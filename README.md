# Minecarts Overhaul

A Fabric mod for Minecraft 1.21.11 that rethinks minecarts and rail transport.

## Documentation

See the [Wiki](https://github.com/Aqu1tain/minecarts-overhaul/wiki) for detailed system documentation.

## Credits

## Requirements

- Minecraft 1.21.11
- Fabric Loader >= 0.18.4
- Fabric API
